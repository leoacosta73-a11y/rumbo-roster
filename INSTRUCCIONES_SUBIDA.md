# CrewRoster - Libro de vuelo

Esta actualización también incluye el funcionamiento offline preparado anteriormente.

1. Copiá todo el contenido de esta carpeta dentro de tu repositorio local `rumbo-roster`.
2. Cuando Windows pregunte, elegí **Reemplazar los archivos en el destino**.
3. En GitHub Desktop dejá seleccionados solamente:
   - `app/page.tsx`
   - `app/globals.css`
   - `public/sw.js`
   - `tests/rendered-html.test.mjs`
4. Resumen del commit: `Agregar libro de vuelo ANAC`
5. Presioná **Commit to main** y luego **Push origin**.

## Uso

- Abrí la nueva pestaña **Libro**.
- Completá tus datos personales, aeronave y totales iniciales.
- Elegí el criterio para el tiempo instrumental.
- Revisá matrícula, horas diurnas/nocturnas, instrumental y aterrizajes de cada vuelo.
- Tocá **Exportar / imprimir**.
- En el diálogo del teléfono o la computadora seleccioná imprimir o guardar como PDF en formato oficio apaisado.

Los tiempos se convierten a décimos usando la tabla acordada: por ejemplo, 1:15 se anota como 1.3.
