# CrewRoster - Totales previos completos

1. Copiá todo el contenido de esta carpeta dentro de tu repositorio local `rumbo-roster`.
2. Elegí **Reemplazar los archivos en el destino**.
3. En GitHub Desktop dejá seleccionados:
   - `app/page.tsx`
   - `app/globals.css`
   - `public/sw.js`
   - `tests/rendered-html.test.mjs`
4. Resumen del commit: `Completar totales previos del libro de vuelo`
5. Presioná **Commit to main** y después **Push origin**.

En la pestaña **Libro**, abrí **Totales previos** con el botón `+`. Al guardar la configuración, el panel se cierra y conserva todos los valores en este dispositivo.
