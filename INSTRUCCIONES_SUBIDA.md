# Segundo simulador y filtro Off

Esta versión recupera la duración correcta de todos los simuladores incluso cuando ARMS informa una jornada completa en Zulu. También cambia **Descanso** por **Off** y agrupa allí `OFF`, `R-OFF`, `RFD`, vacaciones, licencias y suspensiones.

1. Copiá todo el contenido de esta carpeta dentro de tu repositorio local `rumbo-roster`.
2. Cuando Windows pregunte, elegí **Reemplazar los archivos**.
3. En GitHub Desktop escribí: `Corregir segundo simulador y filtro Off`.
4. Presioná **Commit to main** y después **Push origin**.
